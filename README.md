# Telegram Userbot: Рассыльщик и Умный Фармер «Отношений»

Автоматизированный инструмент для Telegram на базе библиотеки **Pyrogram**. Проект содержит два режима работы:
1. **`farmer.py`** — умный авто-фармер для игрового бота отношений («отн») с прокачкой уровней, анти-детект защитой и индивидуальными кулдаунами.
2. **`main.py`** — универсальный цикличный рассыльщик сообщений по списку чатов/пользователей.

---

## ⚡ Особенности `farmer.py` (Умный Фармер)

- **Система уровней (1–18)**: автоматически отслеживает набранные искры и разблокирует действия по мере достижения порогов.
- **Оптимальный выбор действий**: выбирает наиболее эффективное действие по соотношению искр в минуту (`sparks / min`).
- **Человеческая анти-детект защита**:
  - Имитация статуса печати (`ChatAction.TYPING`) с задержкой под длину команды.
  - Естественный разброс реакции человека (0.7–2.3 сек).
  - Рандомизация кулдауна с неточностью до миллисекунд (+30..180 сек).
  - Случайные анти-флуд паузы после отправки.
- **Сохранение прогресса**: файл `farmer_state.json` сохраняет накопленные искры, уровень и состояние кулдаунов при перезапуске.
- **Обработка FloodWait**: автоматически ждёт нужное время при временных ограничениях Telegram.

---

## 📋 Требования

- Python 3.10+
- Telegram API ID и API Hash (получить на [my.telegram.org](https://my.telegram.org))

## 🚀 Установка и настройка

1. **Клонируйте репозиторий:**
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd seller
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   # Windows PowerShell:
   python -m venv venv
   .\venv\Scripts\Activate.ps1

   # Linux / macOS:
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения:**
   Скопируйте шаблон `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
   Откройте `.env` и укажите свои данные:
   ```ini
   API_ID=12345678
   API_HASH=b90c81faa39dff942e0f67284a5692a4

   # Чат или группа с ботом (ID или @username):
   TARGETS=-100123456789

   # Настройки для обычного рассыльщика main.py:
   INTERVAL_MINUTES=5
   MESSAGE_TEXT=.отн сделать комплимент
   ```

## ▶️ Запуск

### Запуск умного фармера отношений:
```bash
python farmer.py
```

### Запуск обычного рассыльщика:
```bash
python main.py
```

> **Примечание**: При первом запуске Pyrogram запросит номер телефона и код подтверждения из Telegram для создания сессии (`my_userbot.session`). Файлы сессий хранятся локально и защищены от попадания в git через `.gitignore`.

---

## 🔒 Безопасность

- Файлы `.env`, `*.session`, `*.session-journal` и `farmer_state.json` внесены в `.gitignore` и **никогда не попадут в репозиторий**.
- Никому не передавайте файл `*.session` и `API_HASH` — они дают прямой доступ к управлению Telegram-аккаунтом.
